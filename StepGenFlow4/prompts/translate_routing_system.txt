## How It Executes (from functional.py)

**FlatPartition:**
```python
flat_inp = inp.reshape(-1, tile_r, tile_c)
flat_mh = multihot.reshape(-1, n_experts)
results = []
for i in range(n_experts):
    mask = flat_mh[:, i] > 0
    results.append(flat_inp[mask])  # variable-length per-expert stream
```

**FlatReassemble:**
```python
ptrs = [0] * n_experts
token_groups = []
for t in range(total_tokens):
    group = []
    for i in range(n_experts):
        if multihot[t, i] > 0:
            group.append(expert_outputs[i][ptrs[i]])
            ptrs[i] += 1
    token_groups.append(torch.stack(group, dim=0))
output = torch.stack(token_groups, dim=0)  # (total, n_active, tile_r, tile_c)
```

## Retiling for Variable-Length Expert Streams

FlatPartition produces variable-length streams. To tile them for matmul, use:
1. `Reshape(graph, (partitioned, i), chunk_size=tile_n, reshape_rank=0, add_outer_dim=True, pad_fn=init_fn.Zero(...))` — pads and chunks
2. `Flatten(graph, reshaped, min_rank=1, max_rank=2)` — flatten chunk dims
3. `Accum(graph, flattened, Tile(..., (tile_n, D)), accum_fn.RetileRow(), init_fn.Empty(...), 1, False, 1024)` — retile into (tile_n, D) tiles

After per-expert compute, use:
- `RetileStreamify(graph, down_output, split_row=True, filter_mask=True)` — untile back to per-token (1, D) tiles, filtering padding
