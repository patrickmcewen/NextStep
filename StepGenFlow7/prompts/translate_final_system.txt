## STeP Accumulation Reference

**Accum(graph, input, output_stream_dtype, fn, init_fn, accum_rank, write_back_mu, compute_bw)**
- Reduces the last `accum_rank` stream dims of the input.
- `accum_fn.Add()`: sum reduction (like `.sum(dim=-3)` repeated `accum_rank` times)
- `accum_fn.RetileRow()`: concatenates tiles along the row dimension
- `init_fn.Zero(shape=(tr, tc), dtype=Float32())`: initial accumulator value
- `output_stream_dtype`: `Tile(tile_dtype=Float32(), shape=(tr, tc))` — can change tile shape

**How Accum executes (`_exec_accum` from functional.py):**

Accum(Add):
```python
data = unwrap(inp)
for _ in range(rank):
    data = data.sum(dim=-3)  # -3 = rightmost stream dim (before tile_r, tile_c)
# Input: (*stream_shape, tile_r, tile_c)
# Output: (*stream_shape[:-rank], tile_r, tile_c)
```

Accum(RetileRow):
```python
inp = unwrap(raw_inp)
for _ in range(rank):
    s = inp.shape
    inp = inp.reshape(*s[:-3], s[-3] * s[-2], s[-1])
# Concatenates tiles along the row dim: (..., N, tile_r, tile_c) -> (..., N*tile_r, tile_c)
```

**BinaryMapAccum(graph, in1, in2, fn, init_fn, rank, write_back_mu, compute_bw)**
- Binary op + accumulation. `rank` = number of inner stream dims to reduce.
- `map_accum_fn.Matmul()`: matmul + sum over `rank` inner dims.
- NOTE: uses `map_accum_fn.Matmul()`, NOT `map_fn.Matmul()`.

## STeP Routing Reference

**FlatPartition(graph, input, control, partition_rank, switch_cycles, write_back_mu, num_consumers)**
- Scatters input to per-branch streams based on multihot control signal.
- Returns a single node. Access per-branch stream as a TUPLE: `(partitioned, i)`.
- Do NOT index `partitioned[i]` or iterate `for x in partitioned` — it is not a list.

**FlatReassemble(graph, inputs, control, reassemble_rank, switch_cycles, write_back_mu)**
- Gathers per-branch outputs back into original order.
- `inputs`: list of per-branch output nodes.

**SelectGen(is_multihot, tensor, n)**
- SOURCE node — call `graph.add_node(select_gen)` manually.
- `tensor`: int64 tensor. For multihot: `(N, n_branches)` with 1s marking selected branches.
- You need SEPARATE SelectGen instances for partition and reassemble.

**How FlatPartition executes (`_exec_flat_partition`):**
```python
flat_inp = inp.reshape(-1, tile_r, tile_c)
flat_mh = multihot.reshape(-1, n)
results = []
for i in range(n):
    mask = flat_mh[:, i] > 0
    results.append(flat_inp[mask])
return results
```

**How FlatReassemble executes (`_exec_flat_reassemble`):**
```python
flat_mh = multihot.reshape(-1, n)
ptrs = [0] * n
token_groups = []
for t in range(total):
    group = []
    for i in range(n):
        if flat_mh[t, i] > 0:
            if ptrs[i] < inputs[i].shape[0]:
                group.append(inputs[i][ptrs[i]])
                ptrs[i] += 1
    if len(group) == 0:
        group.append(torch.zeros_like(inputs[0][0:1].squeeze(0)))
    token_groups.append(torch.stack(group, dim=0))
output = torch.stack(token_groups, dim=0)
ctrl_stream_shape = multihot.shape[:-1]
if ctrl_stream_shape[0] != 1:
    ctrl_stream_shape = (1,) + ctrl_stream_shape
n_active = output.shape[1]
return output.reshape(*ctrl_stream_shape, n_active, tile_r, tile_c)
```

## Retiling for Variable-Length Streams

FlatPartition produces variable-length streams. To tile them for matmul, use:
1. `Reshape(graph, (partitioned, i), chunk_size=tile_n, reshape_rank=0, add_outer_dim=True, pad_fn=init_fn.Zero(...))` — pads and chunks
2. `Flatten(graph, reshaped, min_rank=1, max_rank=2)` — flatten chunk dims
3. `Accum(graph, flattened, Tile(..., (tile_n, C)), accum_fn.RetileRow(), init_fn.Empty(...), 1, False, 1024)` — retile into fixed-size tiles

After per-branch compute, use:
- `RetileStreamify(graph, output, split_row=True, filter_mask=True)` — untile back to per-element (1, C) tiles, filtering padding

## Other Shape Ops

**RepeatStatic(graph, input, repeat_factor)**: repeats each element N times along the innermost stream dim. Used to broadcast along a dimension before a binary op.

**Flatten(graph, input, min_rank, max_rank)**: merges stream dims in range [min_rank, max_rank].

**OffChipStore(graph, input, par_dispatch, store_file_name)**: terminal node that stores the result. The emulator uses this as the output extraction point.
