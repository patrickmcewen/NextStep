## How Routing Executes (from functional.py)

**FlatPartition (`_exec_flat_partition`):**
```python
tile_r, tile_c = inp.shape[-2], inp.shape[-1]
flat_inp = inp.reshape(-1, tile_r, tile_c)
flat_mh = multihot.reshape(-1, n)

assert flat_inp.shape[0] == flat_mh.shape[0], (
    f"Tile count mismatch: {flat_inp.shape[0]} vs {flat_mh.shape[0]}"
)

results = []
for i in range(n):
    mask = flat_mh[:, i] > 0
    results.append(flat_inp[mask])
return results
```

**FlatReassemble (`_exec_flat_reassemble`):**
```python
tile_r, tile_c = inputs[0].shape[-2], inputs[0].shape[-1]
flat_mh = multihot.reshape(-1, n)
total = flat_mh.shape[0]

ptrs = [0] * n
token_groups = []

for t in range(total):
    group = []
    for i in range(n):
        if flat_mh[t, i] > 0:
            if ptrs[i] < inputs[i].shape[0]:
                group.append(inputs[i][ptrs[i]])
                ptrs[i] += 1
    if len(group) == 0:
        group.append(torch.zeros_like(inputs[0][0:1].squeeze(0)))
    token_groups.append(torch.stack(group, dim=0))

output = torch.stack(token_groups, dim=0)  # (total, n_selected, tile_r, tile_c)

# Reshape to match control stream shape
ctrl_stream_shape = multihot.shape[:-1]
if ctrl_stream_shape[0] != 1:
    ctrl_stream_shape = (1,) + ctrl_stream_shape
n_active = output.shape[1]
return output.reshape(*ctrl_stream_shape, n_active, tile_r, tile_c)
```

## Retiling for Variable-Length Streams

FlatPartition produces variable-length streams. To tile them for matmul, use:
1. `Reshape(graph, (partitioned, i), chunk_size=tile_n, reshape_rank=0, add_outer_dim=True, pad_fn=init_fn.Zero(...))` — pads and chunks
2. `Flatten(graph, reshaped, min_rank=1, max_rank=2)` — flatten chunk dims
3. `Accum(graph, flattened, Tile(..., (tile_n, C)), accum_fn.RetileRow(), init_fn.Empty(...), 1, False, 1024)` — retile into fixed-size tiles

After per-branch compute, use:
- `RetileStreamify(graph, output, split_row=True, filter_mask=True)` — untile back to per-element (1, C) tiles, filtering padding
