Multi-output nodes (`Broadcast`, `Parallelize`, `FlatPartition`): access outputs as tuple refs `(node, i)`, NOT `node[i]`.

`FlatPartition` and `FlatReassemble` each need their own `SelectGen` control node.

`FlatPartition` `partition_rank`: controls how many trailing input stream dims are kept in each output.
Output stream per consumer = `(DynDim,) + input.stream.shape[-partition_rank:]`.
The DSL `flat_partition` always flattens the entire stream, so always use `partition_rank=0`.
Similarly, use `reassemble_rank=0` for `FlatReassemble`.

### `offchip_load_ref` → `LinearOffChipLoadRef`

`offchip_load_ref(ref, weight, stride, out_shape_tiled, tile_row, tile_col)` translates to:
```
w = LinearOffChipLoadRef(graph, ref=ref_node, underlying=weight,
        stride=stride, out_shape_tiled=out_shape_tiled,
        tile_row=tile_row, tile_col=tile_col, par_dispatch=...)
```
`LinearOffChipLoadRef` takes `graph` as first arg and auto-registers (do NOT call `graph.add_node`).
Output stream shape: `ref.stream.shape + out_shape_tiled`.

### `ExpandRef` constraints

`ExpandRef(graph, input, ref, expand_rank)` requires that input's last `expand_rank` stream dims
are all 1, and input's leading stream dims exactly match ref's leading dims. It CANNOT bridge
static→dynamic shapes. The DSL enforces this by using `offchip_load_ref` for dynamic cases.

## Fixing Errors

When you receive an error on a subsequent turn, make a **targeted fix** — do NOT rewrite the entire implementation from scratch. Identify the specific lines that failed, reason about why, and change only those lines. Rewriting from scratch discards working parts of your solution and often reintroduces bugs you already fixed. Output the full corrected code, but keep all lines that were already correct unchanged.
To be clear, you still have to output the full code. Just outputting a few lines as a diff is not sufficient.

## Rules

- **DO NOT INCLUDE ANY IMPORT STATEMENTS.** All imports are injected automatically. Any `import` or `from ... import` line WILL cause errors.
- Output ONLY a `build_graph(dims, tensors)` function that returns `(graph, output_op)` — no imports, no top-level code.
- Create a single `Graph()` at the top of the function.
- Replace EVERY DSL call with its corresponding STeP node — no DSL calls remain.
- Do NOT call `execute_values` — the graph is executed externally.
- Do NOT include PyTorch tensor operations (`torch.*`, `F.*`, `*`, `+`, `.sum()`, etc.) on data tensors.
- The only Python allowed is: reading `dims`/`tensors`, scalar math, control flow, and list operations.
- Always end with: `graph = infer_broadcast(graph); return graph, output`
- The graph's output must match the reference exactly (rel_err < 1e-5).
