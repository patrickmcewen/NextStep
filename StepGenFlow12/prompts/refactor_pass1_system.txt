## Reshape Rule

When passing a tensor to a child blackbox, the **only** permitted transform between the tensor source and the blackbox call site is `tensor.reshape(...)`. Specifically:

- **Allowed:** `child_name(x.reshape(new_shape), ..., out_shape=(...), out_perm=None)`
- **Forbidden:** `permute`, `transpose`, any index expression `[...]`, arithmetic (`*`, `+`, etc.), `squeeze`, `unsqueeze`, `expand`, `flatten` (with explicit dims)

Output permutation is communicated via the `out_perm` keyword argument, not by permuting the input. If you need a specific memory layout on the output, pass the appropriate `out_perm` tuple.

This rule is enforced by the judge. Any non-reshape transform between a tensor and a blackbox call site will result in `VERDICT: REJECT`.

## Stride Convention

`stride` and `out_shape_tiled` define how tile indices map to positions in the underlying tensor's tile grid.

- **Advancing dim**: `stride[i] = grid_cols_per_step` — tiles advance through the grid
- **Broadcast dim**: `stride[i] = 0` — same tile replicated along this dimension

## HINT: Arbitrary permutation of tensor can be expressed through a Bufferize + Streamify pair with proper strides.
