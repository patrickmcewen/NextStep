NOTE about the kinds of code you will see:
 - STeP has two basically equivalent forms with ops of similar names, and different files may be in one or the other of these forms.
 - DSL form is function-style (e.g. `binary_matmul(a, b)`); IR form is class instantiation against a `graph` (e.g. `BinaryMap(graph, a, b, fn=map_fn.Matmul())`). Treat a target and a candidate as using the SAME op if they appear in the same group below.
 - here is the grouping between different forms of STeP nodes:

 # BinaryMap family — DSL `binary_*` ↔ IR `BinaryMap(graph, a, b, fn=map_fn.<X>())`
   binary_matmul              ↔ map_fn.Matmul
   binary_mul                 ↔ map_fn.Mul
   binary_add                 ↔ map_fn.Add
   binary_div                 ↔ map_fn.Div
   binary_is_equal            ↔ map_fn.IsEqual
   binary_row_wise_append     ↔ map_fn.RowWiseAppend
   binary_set_offset          ↔ map_fn.SetOffset
   binary_cache_write_addr_gen ↔ map_fn.CacheWriteAddrGen

 # UnaryMap family — DSL `unary_*` ↔ IR `UnaryMap(graph, x, fn=map_fn.<X>())`
   unary_silu                 ↔ map_fn.Silu
   unary_square               ↔ map_fn.Square
   unary_exp                  ↔ map_fn.Exp
   unary_rsqrt                ↔ map_fn.Rsqrt
   unary_pow2                 ↔ map_fn.Pow2
   unary_mul_imm              ↔ map_fn.MulImmediate(c)
   unary_add_imm              ↔ map_fn.AddImmediate(c)
   unary_sub_imm              ↔ map_fn.SubImmediate(c)
   unary_rowwise_sum          ↔ map_fn.RowWiseSum
   unary_select_to_scalar     ↔ map_fn.SelectToScalar
   unary_to_const_int         ↔ map_fn.ToConstInt(c)
   unary_mask_row             ↔ map_fn.MaskRow

 # Accum family — DSL `accum_*` ↔ IR `Accum(graph, x, fn=accum_fn.<X>(), accum_rank=...)`
   accum_add                  ↔ accum_fn.Add        (out tile: elem)
   accum_mul                  ↔ accum_fn.Mul        (out tile: elem)
   accum_max                  ↔ accum_fn.Max        (out tile: elem)
   accum_retile_row           ↔ accum_fn.RetileRow  (out tile: row)
   accum_retile_col           ↔ accum_fn.RetileCol  (out tile: col)
   accum_signal_req_all_read  ↔ accum_fn.SignalReqAllRead (out: Tile(Uint64,(1,1)))

 # Fused matmul+accum
   binary_map_accum           ↔ BinaryMapAccum(graph, a, b, fn=map_accum_fn.Matmul(), init_fn=Zero(...))

 # Off-chip memory
   offchip_load               ↔ LinearOffChipLoad
   offchip_load_ref           ↔ LinearOffChipLoadRef
   dyn_offchip_load           ↔ DynLinearOffChipLoad
   random_offchip_load        ↔ RandomOffChipLoad
   offchip_store              ↔ OffChipStore
   random_offchip_store       ↔ RandomOffChipStore

 # Stream / shape transforms
   promote                    ↔ Promote(promote_rank=...)
   promote_outer              ↔ PromoteOuter
   flatten                    ↔ Flatten(min_rank, max_rank)
   reshape_stream             ↔ Reshape(chunk_size, reshape_rank)
   reshape_pad_stream         ↔ ReshapePadStream(chunk_size, reshape_rank)
   expand_ref                 ↔ ExpandRef(ref, expand_rank)
   repeat_ref                 ↔ RepeatRef(ref)
   repeat_static              ↔ RepeatStatic(repeat_factor)
   streamify                  ↔ Streamify(stride, out_shape_tiled)
   retile_streamify           ↔ RetileStreamify(split_row, chunk)
   bufferize                  ↔ Bufferize(rank)
   dyn_streamify              ↔ DynStreamify(input, ref, repeat_rank)
   restream                   ↔ composite: Promote + RetileStreamify×2 + Bufferize + Streamify + Accum(RetileCol) + Accum(RetileRow)

 # Reassemble
   static_reassemble          ↔ StaticReassemble
   flat_reassemble            ↔ FlatReassemble(control, reassemble_rank)

 # Multi-output / control (each produces N branches, indexed (node, i))
   broadcast                  ↔ Broadcast(num_consumers=N)
   parallelize                ↔ Parallelize(parallelize_rank, num_consumers=N)
   flat_partition             ↔ FlatPartition(control, partition_rank, num_consumers=N)
   eager_merge                ↔ EagerMerge(inputs, input_rank)   (always 2 output streams: data, select)

 # Address / metadata generators
   select_gen                 ↔ SelectGen(tensor, n, is_multihot=True)
   metadata_gen               ↔ MetadataGen(tensor)
   expert_addr_gen            ↔ ExpertAddrGen(num_tile_per_expert, expert_addr_base)
   cache_read_addr_gen        ↔ CacheReadAddrGen(idx, seq_len, row_offset)
   filter_last_tile           ↔ FilterLastTile(seq_len)

 # Flatmap
   flatmap_filter_row_streamify ↔ FlatmapFilterRowStreamify(input, mask)
   flatmap_counter              ↔ FlatmapCounter(input)
