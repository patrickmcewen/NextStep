## KEY POINT ABOUT MEMORY

The key from the above code is to understand that the on-chip memory capacity is
determined by tile sizes flowing through STeP operators.
Therefore, to reduce on-chip memory, you may want to reduce the tile size of operators.
It may result in more off-chip memory traffic and slower latency, but that is okay because
we need to meet the memory capacity constraint.
