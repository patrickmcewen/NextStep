## DSL Functions for This Pass

### Accumulation
```python
def accum_add(x, rank=1):
    """Sum-reduce over the innermost `rank` stream dims (dim -3).
    Mirrors Accum(accum_fn.Add)."""
    for _ in range(rank):
        x = x.sum(dim=-3)
    return x

def accum_mul(x, rank=1):
    """Product-reduce over the innermost `rank` stream dims (dim -3).
    Mirrors Accum(accum_fn.Mul)."""
    for _ in range(rank):
        x = x.prod(dim=-3)
    return x

def accum_retile_row(x, rank=1):
    """Merge stream dim into tile rows. Mirrors Accum(accum_fn.RetileRow)."""
    for _ in range(rank):
        s = x.shape
        x = x.reshape(*s[:-3], s[-3] * s[-2], s[-1])
    return x

def accum_retile_col(x, rank=1):
    """Merge stream dim into tile cols. Mirrors Accum(accum_fn.RetileCol)."""
    for _ in range(rank):
        s = x.shape
        x = x.reshape(*s[:-3], s[-2], s[-3] * s[-1])
    return x
```

### Routing
```python
def flat_partition(x, control, n):
    """Partition tiles by multihot control signal.
    Returns list of n tensors, each containing tiles routed to that partition."""
    tile_r, tile_c = x.shape[-2], x.shape[-1]
    flat_inp = x.reshape(-1, tile_r, tile_c)
    flat_mh = control.reshape(-1, n)
    assert flat_inp.shape[0] == flat_mh.shape[0]
    results = []
    for i in range(n):
        mask = flat_mh[:, i] > 0
        results.append(flat_inp[mask])
    return results

def flat_reassemble(inputs, control):
    """Reassemble partitioned outputs using multihot control signal.
    Returns tensor with shape (*ctrl_stream_shape, n_active, tile_r, tile_c)."""
    n = len(inputs)
    tile_r, tile_c = inputs[0].shape[-2], inputs[0].shape[-1]
    flat_mh = control.reshape(-1, n)
    total = flat_mh.shape[0]
    ptrs = [0] * n
    token_groups = []
    for t in range(total):
        group = []
        for i in range(n):
            if flat_mh[t, i] > 0:
                if ptrs[i] < inputs[i].shape[0]:
                    group.append(inputs[i][ptrs[i]])
                    ptrs[i] += 1
        if len(group) == 0:
            group.append(torch.zeros_like(inputs[0][0:1].squeeze(0)))
        token_groups.append(torch.stack(group, dim=0))
    output = torch.stack(token_groups, dim=0)
    ctrl_stream_shape = control.shape[:-1]
    if ctrl_stream_shape[0] != 1:
        ctrl_stream_shape = (1,) + ctrl_stream_shape
    n_active = output.shape[1]
    return output.reshape(*ctrl_stream_shape, n_active, tile_r, tile_c)
```

## Conversion Rules

### Accumulation
| PyTorch | DSL |
|---|---|
| `x.sum(dim=-3)` | `accum_add(x, rank=1)` |
| `x.sum(dim=-3).sum(dim=-3)` | `accum_add(x, rank=2)` |
| `x.prod(dim=-3)` | `accum_mul(x, rank=1)` |

### Routing — Gather/Scatter to flat_partition/flat_reassemble

If the code uses gather/scatter patterns (nonzero + indexing, boolean masking, scatter-add), convert to `flat_partition` / `flat_reassemble`. The multihot control tensor drives which tiles go to which partition.

**Pattern 1 — Simple boolean indexing:**
```python
# BEFORE:
for i in range(n):
    mask = control[:, i] > 0
    part_i = data[mask]
    # ... compute on part_i ...
    results.append(output_i)

# AFTER:
partitions = flat_partition(data, control, n)
for i in range(n):
    part_i = partitions[i]
    # ... compute on part_i ...
    results.append(output_i)
result = flat_reassemble(results, control)
```

**Pattern 2 — Gather/compute/scatter with nonzero + idx (common in sparse dispatch):**

IMPORTANT: `flat_partition` and `flat_reassemble` operate on TILED tensors (from `offchip_load`). The multihot control is a non-tiled tensor (from `select_gen`). The tiled data's flattened tile count must match the control's flattened row count.

```python
# BEFORE:
y = torch.zeros_like(x)
for i in range(n):
    mask = multihot[:, i] > 0
    idx = torch.nonzero(mask).squeeze(1)
    if idx.numel() == 0:
        continue
    x_sel = x[idx]                    # gather
    # ... compute on x_sel ...
    y[idx] = y[idx] + result          # scatter-add

# AFTER:
# x_load must be TILED — use the offchip_load output, NOT a dense tensor
x_load = offchip_load(tensors["x"], stride=(1,), out_shape_tiled=(B//tile_n,),
                       tile_row=tile_n, tile_col=D)
control = select_gen(tensors["multihot"])
partitions = flat_partition(x_load, control, n)
outputs = []
for i in range(n):
    part_i = partitions[i]            # only routed tiles
    # ... DSL compute on part_i ...
    outputs.append(result_i)
y = flat_reassemble(outputs, control)  # reassemble in original order
# Then reduce/weight as needed with accum_add, binary_mul, etc.
```

Key points:
- `flat_partition` replaces the nonzero + gather pattern
- `flat_reassemble` replaces the scatter-add pattern
- The per-partition computation only operates on routed tiles (variable count)
- No need for `torch.zeros_like`, `torch.nonzero`, indexing with `[idx]`, or `F.pad`
