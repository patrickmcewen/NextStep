## DSL Functions for This Pass

These functions are pre-imported and available at runtime. Here are their exact implementations:

```python
def offchip_load(underlying, stride, out_shape_tiled, tile_row, tile_col, transposed=False):
    """Load an untiled tensor into tiled stream form.
    Returns tiled tensor with shape (1, *out_shape_tiled, tile_row, tile_col).
    """
    R, C = underlying.shape[-2], underlying.shape[-1]
    grid_r, grid_c = R // tile_row, C // tile_col
    batch_shape = underlying.shape[:-2]
    used_R, used_C = grid_r * tile_row, grid_c * tile_col
    if used_R != R or used_C != C:
        underlying = underlying[..., :used_R, :used_C]
    tiled = underlying.reshape(*batch_shape, grid_r, tile_row, grid_c, tile_col)
    ndim = tiled.ndim
    perm = list(range(len(batch_shape))) + [ndim - 4, ndim - 2, ndim - 3, ndim - 1]
    tiled = tiled.permute(*perm)
    flat = tiled.reshape(-1, tile_row, tile_col)
    ranges = [torch.arange(s) for s in out_shape_tiled]
    grids = torch.meshgrid(*ranges, indexing="ij")
    linear_idx = sum(g.long() * int(s) for g, s in zip(grids, stride))
    result = flat[linear_idx.long()]
    if transposed:
        result = result.transpose(-2, -1)
    return result.unsqueeze(0)  # prepend leading 1


def select_gen(underlying):
    """Pass through a pre-computed control tensor as-is."""
    return underlying


def offchip_store(x):
    """Untile a tiled tensor back to dense 2-D form."""
    tile_r, tile_c = x.shape[-2], x.shape[-1]
    if x.shape[0] == 1:
        x = x[0]
    tiled = x.shape[:-2]
    if len(tiled) == 0:
        return x
    if len(tiled) == 1:
        return x.reshape(tiled[0] * tile_r, tile_c)
    Tc = tiled[-1]
    ndim = len(x.shape)
    perm = list(range(ndim - 4)) + [ndim - 4, ndim - 2, ndim - 3, ndim - 1]
    x = x.permute(*perm).contiguous()
    total_rows = tile_r
    for d in tiled[:-1]:
        total_rows *= d
    return x.reshape(int(total_rows), int(Tc * tile_c))
```

## Stride Convention

`stride` and `out_shape_tiled` define how tile indices map to positions in the underlying tensor's tile grid.

- **Advancing dim**: `stride[i] = grid_cols_per_step` — tiles advance through the grid
- **Broadcast dim**: `stride[i] = 0` — same tile replicated along this dimension

**Common patterns:**

| Tensor | Shape | Tiling | stride | out_shape_tiled |
|---|---|---|---|---|
| Input x | (B, D) | tile_n × D over batch | `(1,)` | `(B//tile_n,)` |
| Weight w | (D, F) | D × F broadcast over batch | `(0,)` | `(B//tile_n,)` |
| GEMM A | (M, K) | tm × tk over (M_g, N_g, K_g) | `(K_g, 0, 1)` | `(M_g, N_g, K_g)` |
| GEMM B | (K, N) | tk × tn over (M_g, N_g, K_g) | `(0, 1, N_g)` | `(M_g, N_g, K_g)` |

## CRITICAL: Use Proper Tile Sizes

If `dims` contains `tile_n` (or similar tile size parameters), you MUST use them for tiling. NEVER load an entire dimension as one giant tile.

```python
# WRONG — loads entire batch as one tile, destroys streaming:
x = offchip_load(tensors["x"], stride=(0,), out_shape_tiled=(1,),
                  tile_row=B, tile_col=D).squeeze(0)

# RIGHT — streams over batch tiles:
x_load = offchip_load(tensors["x"], stride=(1,), out_shape_tiled=(B//tile_n,),
                       tile_row=tile_n, tile_col=D)
```

1. **Replace manual tiling patterns** with `offchip_load`:
   ```python
   # BEFORE:

   # AFTER:

                          tile_row=D, tile_col=F)
   ```

2. **Replace final untiling** with `offchip_store`:
   ```python
   # BEFORE:
   return result.reshape(B, D)
   # AFTER:
   return offchip_store(result)
   ```

3. **Replace control tensor access** with `select_gen`:

## What NOT to Change

- **Compute operations**: Keep `torch.matmul`, `F.silu`, `*`, `+`, `/`, `**`, `x.sum(dim=-3)` exactly as-is
- **Control flow**: Keep `for` loops, `if` statements, list operations as-is
- **Routing / dispatch logic**: Keep gather/scatter patterns (`x[idx]`, `y[idx] = ...`), boolean masking (`mask > 0`), `torch.nonzero`, `F.pad` for stream padding — these are routing operations that will be converted to `flat_partition`/`flat_reassemble` in a later pass
- **Accumulation**: Keep `.sum(dim=-3)` as-is
- **torch.zeros_like / torch.zeros**: Keep output buffer initialization as-is
- **torch.stack**: Keep tensor stacking as-is
