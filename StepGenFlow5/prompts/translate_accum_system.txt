## STeP Accumulation Reference

**Accum(graph, input, output_stream_dtype, fn, init_fn, accum_rank, write_back_mu, compute_bw)**
- Reduces the last `accum_rank` stream dims of the input.
- `accum_fn.Add()`: sum reduction (like `.sum(dim=-3)` repeated `accum_rank` times)
- `accum_fn.RetileRow()`: concatenates tiles along the row dimension (like reshape + flatten)
- `init_fn.Zero(shape=(tr, tc), dtype=Float32())`: initial accumulator value
- `output_stream_dtype`: `Tile(tile_dtype=Float32(), shape=(tr, tc))` — can change tile shape

**How Accum executes (`_exec_accum` from functional.py):**

Accum(Add):
```python
data = unwrap(inp)
for _ in range(rank):
    data = data.sum(dim=-3)  # -3 = rightmost stream dim (before tile_r, tile_c)
# Input: (*stream_shape, tile_r, tile_c)
# Output: (*stream_shape[:-rank], tile_r, tile_c)
```

Accum(RetileRow):
```python
inp = unwrap(raw_inp)
for _ in range(rank):
    s = inp.shape
    inp = inp.reshape(*s[:-3], s[-3] * s[-2], s[-1])
# Concatenates tiles along the row dim: (..., N, tile_r, tile_c) -> (..., N*tile_r, tile_c)
```

## Other Shape Ops You May Need

**RepeatStatic(graph, input, repeat_factor)**: repeats each element N times along the innermost stream dim. Used to broadcast along a dimension before a binary op.

**Flatten(graph, input, min_rank, max_rank)**: merges stream dims in range [min_rank, max_rank].

**OffChipStore(graph, input, par_dispatch, store_file_name)**: terminal node that stores the result. The emulator uses this as the output extraction point.
